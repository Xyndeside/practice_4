# Конференции.РФ

Портал бронирования помещений для конференций (аудитория, коворкинг, кинозал).
**Стек:** NestJS 10 · TypeORM · PostgreSQL · HTML/CSS/JS без внешних зависимостей (работает без интернета).

## Запуск

```bash
cp .env.example .env          # при необходимости поправьте доступ к БД
docker compose up -d          # PostgreSQL (или используйте свой сервер, БД "conferences")
npm install
npm run build
npm run start:prod            # http://localhost:3000
```

Для разработки: `npm run start:dev`. Переменные окружения: `PORT`, `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASS`, `DB_NAME`, `SESSION_SECRET`.
Таблицы создаются автоматически; такой же скрипт лежит в `sql/schema.sql`. При первом старте добавляются помещения и администратор.

**Администратор:** логин `Conf2027`, пароль `Demo77`.

## Страницы

| Файл | Назначение |
|---|---|
| `/` (index.html) | Авторизация, ссылка «Еще не зарегистрированы? Регистрация» |
| `/register.html` | Регистрация с валидацией на форме |
| `/bookings.html` | Личный кабинет: заявки и отзывы (только после статуса «Завершено») |
| `/new-booking.html` | Новая заявка: помещение из списка, дата, способ оплаты |
| `/admin.html` | Панель администратора: карточки, фильтры, смена статуса |

Вёрстка адаптивная, проверена на 390×844.

## API

| Метод | URL | Доступ |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | все |
| GET | `/api/auth/me`, `/api/rooms` | все |
| POST | `/api/bookings` | пользователь |
| GET | `/api/bookings/my` | пользователь |
| POST | `/api/bookings/:id/review` | пользователь (своя завершённая заявка) |
| GET | `/api/admin/bookings?status=&roomId=&q=` | администратор |
| PATCH | `/api/admin/bookings/:id/status` | администратор («Мероприятие назначено» / «Завершено») |

## Правила валидации (клиент и сервер)

- логин — латиница и цифры, ≥ 6 символов, уникальный;
- пароль — ≥ 8 символов (хранится как bcrypt-хэш);
- ФИО — кириллица и пробелы; телефон — `8(XXX)XXX-XX-XX`; email — корректный формат; все поля обязательны.
